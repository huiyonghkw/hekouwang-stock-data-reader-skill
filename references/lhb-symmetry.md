# 龙虎榜席位 · 买卖对称度（解读护栏）

> 席位类内容**别信游资揭秘帖**，用可复算指标判性质。详见 harness memory `lhb-seat-symmetry-test`。

## 两个核心数

对每只上榜股、每个营业部席位：

1. **上榜频次**（在 `lhb_detail.csv` 里该席位出现次数）
2. **买卖次数比** = 买入条数 ÷ 卖出条数

| 模式 | 典型特征 | 解读边界 |
|---|---|---|
| **通道型** | 高频 + 比值 0.85–1.15 | 上榜是常态，**零方向信息** |
| **集中型** | 低频 + 单边 + 金额集中 | 才**可能**带信息，仍不能推走势 |

`analyze.py` 会输出 `n_bidirectional_seats`、`n_channel_like_seats` 与 `seat_symmetry` 前 10 席。

## ⛔ 必须先建当日基准

单票孤证会被打脸（例：「29 次很少」→ 当日全场最稀有席位频次中位数只有 7 次）。

**做法**：`stock_lhb_detail_em(当日)` 拉全市场上榜股 → 逐只算六项指标 → 看目标票落在 P25–P75 还是极端分位。落在中间带 = 平平无奇，别往下编故事。

## 合规红线

- `stock_lhb_detail_em` 带的「上榜后 N 日涨跌幅」字段 **一律不用**（收益率回溯 = 金融红线）。
- 结论只能到「识别席位性质」，**不能推身份、不能推买卖点**。
- 以龙虎榜/资金流为主钩子的小红书版 → 见 `compliance.md` 高风险渠道规则。
