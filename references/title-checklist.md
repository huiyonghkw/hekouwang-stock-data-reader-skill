# 标题与封面 · 合规自检清单

出稿前逐条打勾；任一条不通过 → 改标题或改渠道。

## 全平台禁词（标题 / 封面 / 摘要）

- [ ] 无：买入、卖出、抄底、加仓、减仓、止损、目标价、看多/看空、翻倍、稳赚、上车、进群
- [ ] 无暗示持牌/投顾身份
- [ ] 无「必涨」「铁底」「主力建仓」类方向判断

## 小红书额外（若发小红书）

- [ ] 形态是**复盘 / 算账 / 名词科普**，不是「机构观感」
- [ ] 标题走解惑式：「这笔钱到底发了多少」「XX 名词一张图看懂」
- [ ] **不以**主力进出、龙虎榜席位、资金流为主钩子
- [ ] 文末有风险提示条；**零站外导流**（无公众号/微信/外链）

## 公众号 / 头条

- [ ] 标题前部尽量纯中文（头条封面钩子同理）
- [ ] 标注数据截止时点
- [ ] 文末固定风险提示条（见 `compliance.md`）

## 龙虎榜 / 席位专题

- [ ] 已跑 `analyze.py` 对称度指标
- [ ] 若下结论涉及「罕见/集中」，已对照当日全市场基准（见 `lhb-symmetry.md`）
- [ ] 正文写清：只识别席位性质，不预测涨跌
